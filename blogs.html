Question-1: What are the different ways to select an element in the DOM?

Answer: There is we can use this method to get an element in the DOM. getElementById(), getElementsByClassName(), getElementsByTagName(), querySelector(), querySelectorAll()

Question-2: What is the difference between innerHTML, innerText, and textContent?

Answer: Difference between innerHtml, innerText, and textContent:
1. innerHtml = It provides html text of an entire element.
2. innerText = It provides text on an element.
3. textContent = It provides raw text of an element.

Question-3: What is event delegation in the DOM?

Answer: Instead of attaching events to many elements, let a parent handle them and check to respond accordingly.

Question-4: What is event bubbling in the DOM?

Answer: Event bubbling means when you click an element, that event also triggers on all its parent elements, like bubbles rising to the surface.

Question-5: How do you create, add, and remove elements using JavaScript?

Answer: To create, add, and remove elements using JavaScript:
1. Create: document.createElement()
2. Add: appendChild()
3. Remove: element.remove()
